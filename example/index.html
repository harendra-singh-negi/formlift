formlift: turn any PDF into a fillable web form

formlift is an open-source TypeScript library that keeps your PDF as it is and puts real form fields on top of it. No AI and no server-side conversion.

Features

  • Auto-detects fields: answer lines, checkboxes, blanks and table cells from the PDF's own drawing
  • Drag-and-drop form builder with 20 field types
  • Conditional logic: show, required and read-only conditions, follow-up questions, comments
  • Validation and a fill-in UI that works on desktop and phone
  • Completed-PDF export with answers, signatures and attachments
  • React components, a framework-free element for Angular, Vue and plain JavaScript, and a headless core

Install

npm install formlift
